## 一、五阶段生产管线

### 1.1 选题 — "点子民主化" + AI辅助

| 环节 | 做法 | 工具 |
|------|------|------|
| 全员选题 | 飞书"点子群"，任何人提交标题+封面即可参与选题，不限岗位 | 飞书群 |
| AI资料搜集 | OpenClaw Bot 自动搜集背景资料、生成封面预览 | OpenClaw (飞书AI机器人) |
| 壳理论 | 先定标题和封面（壳），再填充硬核内容（核）。"没人点开，内容再好也没用" | -- |
| 含潘量指标 | 量化Tim (潘天鸿) 在片头出镜时长与观众留存率的关系，数据驱动出镜决策 | 飞书多维表格 |

**核心逻辑**：标题决定传播动机 (Hook)，封面决定点击率。在选题阶段就用AI降低信息搜集成本，而非到了后期才用AI。

### 1.2 策划 — 工作流变化最大的环节 (2024→2026)

传统流程 vs 新流程：

```
传统: 文字脚本 → 各自脑中渲染画面 → 拍摄 (沟通成本巨大，信息不对称)
新流程: 文字脚本 → AI生成概念参考短片 → 全员围绕参考片对齐预期 → 实拍 → 人工后期成片
```

- **AI概念片的价值不在精度，在对齐**。让摄影、灯光、特效、剪辑所有人都"看到"同一部片子该长什么样
- **核心原则：AI只发生在前期策划阶段，后期全人工**
- 参考片消除信息差，把"你懂我的意思吗"变成"就按这个感觉来"

### 1.3 拍摄 — 设备使用真相 + 差异化策略

| 设备 | 实际使用情况 |
|------|-------------|
| 1-2万元微单 (Sony A7系列等) | **主力机型，使用率最高** |
| ALEXA 35 / RED 电影机 | "基本躺柜里吃灰" — 太重是最大痛点 |
| 专业防水壳 + 水下拍摄 | 从冷门配件变成**差异化稀缺资产**，甲方愿溢价买单 |
| 自研水下录音系统 | DJI Mic 3 + 3D打印配件 + 潜水面罩，实现水下同步录音 |

**设备管理**：QR Code扫码自动出入库，每件设备追踪使用频率。

### 1.4 后期 — 分段专业化流水线

| 环节 | 负责人 | 说明 |
|------|--------|------|
| 对轨 | 剪辑师 | 多机位素材对轨，输出到飞书妙记转文字 |
| 大纲筛选 | 编导 | 通过文字快速筛选40-50分钟采访的有效段落 |
| 分段剪辑 | 剪辑师 | 按白板列出的"有趣事件"分段剪，非顺序剪 |
| A-Copy | 编导 | 第一版内部审片 |
| B-Copy | Tim | 第二版审片 (多数情况到此即可) |
| C/D/E-Copy | Tim | 偶尔较真时才会到多轮 |
| 调色 | 调色师 | 全公司仅1位专属调色师，有时同时处理5条片子 |
| 混音 | 混音师 | 人工推子调整动态，BGM定在比人声低18dB |
| 补录旁白 | Tim | **最终旁白必须真人+高保真麦重录，绝不用AI** |

### 1.5 数据复盘 — AI驱动的数据中台

- 设立**数据中台**岗位，专职数据分析
- 飞书多维表格每15分钟自动同步B站/抖音/YouTube全平台数据
- AI一句话生成可视化仪表盘 (自然语言 → 飞书多维表格图表)
- **AI点映团**：AI模拟"公关专家""科技博主""路人"等多角色审片，生成"无趣时间表"定位流失节点
- 绩效考评维度：涨粉量 + 全站排行榜入榜次数 (全年目标6次榜一)

## 二、AI双轨策略 (最核心的方法论)

### 2.1 双轨架构

| 轨道 | 适用范围 | AI角色 | 策略意图 |
|------|----------|--------|----------|
| **AI辅助** | 主频道全部内容 | AI只在前期(选题/策划/封面)协助，后期全手工 | "坚持手工古法打造"，保护品质不翻车 |
| **AI主导** | 短片组 @一步一部Rolling | AI主导创作短片、参加AI影展 | 封闭沙盒探索边界，不污染主力内容 |

### 2.2 三条不可逾越的底线

1. **不生成Tim本人的人像** — "观众太熟悉我长什么样了，AI生成会破坏面孔信任，恐怖谷效应逃不掉"
2. **AI语音模型仅内部使用** — 剪辑师搭框架用、甲方审片参考用。正式发布版**必须真人+高保真麦重录**
3. **AI视频只补充抽象画面** — 梦境、特效、概念示意。不取代真人实拍内容

### 2.3 AI在各环节的具体落地

| 场景 | AI应用 | 价值 |
|------|--------|------|
| 选题 | OpenClaw Bot自动搜集资料、生成封面 | 降低信息搜集成本，"永不疲倦的研究助理" |
| 策划 | AI生成概念参考片 | 对齐预期、消除沟通成本 |
| 封面设计 | 即梦4.0 (飞书集成)，5分钟生成20+封面方案 | 前置封面制作，避免成片后返工 |
| 剪辑参考 | 自训Tim语音模型搭框架抓节奏 | 减少Tim重复补录的嗓子消耗 |
| 特效补充 | AI生成抽象画面 (梦境、概念示意) | 替代传统数周渲染时间 |
| 运营分发 | AI帮写标题、生成多平台分发版本 | 提效 |
| 数据 | AI自然语言驱动数据分析仪表盘 | 从体力搬运变策略制定 |
| 内部工具 | AI编程开发订餐平台等内部工具 | 降低开发成本 |
| 电商 | AI Agent做阿里国际站多语言自动化 | 跨境电商 |

### 2.4 AI标注风波 (2026年3月)

- 一支无人机测评视频的"英雄镜头"用了AI生成，按规定标注了"AI生成"
- 评论区几乎全是批评："AI画面看多了生理不适""缺少打动人心的灵魂""少了直击心灵的温暖和生命力"
- Tim在北影节的回应：那个镜头生成了**500+候选片段**、熬了**3-4个通宵**迭代筛选
- Tim的反思："因为我们主动写了AI生成，评论区基本全是骂声。**如果没标注呢？评论可能完全不一样。**"
- 核心矛盾：合规标注 vs 观众接受度。技术可行 ≠ 情感可接受

## 六、核心创作方法论

### 6.1 HKRR内容定位法则

- **H**appy (快乐) — 观众看完要有情绪收获
- **K**nowledge (知识) — 提供增量信息
- **R**esonance (共鸣) — 触发"我也是"的心理认同
- **R**hythm (节奏) — 张弛有度，2分钟内切换多种叙事模式

### 6.2 HAMD创作四步法

- **H**ook — 传播钩子：标题决定点击动机
- **A**nchor — 记忆锚点：让观众记住的核心信息
- **M**ind Map — 无序思维导图：先发散再收敛，不拘泥于线性逻辑
- **D**ifferent — 差异视角：区别于同类内容的独特角度

### 6.3 剪辑节奏公式

- 前8秒展示核心画面 (视觉冲击建立留存)
- 20秒品牌背书 (建立信任)
- 2分钟内切换多种叙事模式 (幽默/特效/连线，防止疲劳)
- 坚持"砍掉无聊时间" — 疯狂删除内容，杜绝空镜混剪
- BGM比人声低18dB (固定标准)

### 6.4 三个管理锦囊 (来自Tim父亲 — 圆通总裁)

1. **盲目换人不解决本质问题** — 同样错误反复出现是系统问题，不是人的问题
2. **有效量化、降低信息差** — 是企业运作的核心
3. **人性经不起挑战，商业是切蛋糕的艺术** — 分配公平最重要

## 七、对赛博瑞的启示

### 7.1 可直接迁移的策略

1. **AI参考片对齐预期**：在赛博瑞的"文案→分镜"管线中，插入一个AI生成概念图/概念短片的环节，让分镜师和拍摄者对齐视觉预期。这正是赛博瑞分镜引擎可以增强的方向。

2. **数据中台 + AI仪表盘**：赛博瑞目前没有数据复盘环节。可以加一个简单的全平台数据自动同步 + AI一句话生成周报的能力。

3. **AI双轨制**：赛博瑞的主线内容保持AI辅助（现状），但可以单开一个实验轨道尝试AI主导生成完整短视频，封闭测试不污染主线。

4. **封面前置**：现在的流程是"文案→分镜→输出"，封面是事后诸葛亮。影视飓风的做法是选题阶段就出封面，用封面倒逼内容方向。

5. **"含潘量"式指标**：对赛博瑞而言，可以定义类似指标——比如不同人设的脚本在不同品类中的留存率差异，数据驱动人设选择。

### 7.2 需要警惕的

- **AI标注的双刃剑**：如果赛博瑞未来产出的内容包含AI生成部分，是否标注、如何标注，需要策略性思考（合规 vs 观众接受度）
- **AI语音的底线**：影视飓风坚持最终旁白真人录制，对赛博瑞的D先生人设同样适用——观众对人声的真实性有直觉级敏感度
- **不要因为AI可用就全盘AI化**：影视飓风的核心竞争力仍然是"人"——Tim本人出镜、真人实拍、人工调色混音。AI是加速器，不是替代品
