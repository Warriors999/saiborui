# 铁律验证

## 概述

## 竞品违规数据

基于对8个品类、24+位创作者的竞品分析，最常见的三类违规：

1. **电商味过重** (80%违规率): "震撼上市""全新升级""不容错过"等PR稿用语
2. **态度密度低** (72%违规率): 观点模棱两可，"还不错""挺好的""可以考虑"
3. **口语化不足** (68%违规率): 文案腔太重，"为用户带来极致体验"而非"用起来真舒服"

### 来源
- 竞品分析管线自动采集，持续更新
- 数据截止: 2026-06-02

## 验证流程

```
脚本生成 → 14项审计检查 → 逐项通过/不通过
    ↓
不通过项 → Auto-Fix循环（最多3轮）
    ↓
全数通过 → 评分卡输出 → 人工复审 → 定稿
```

每轮Auto-Fix针对具体违规类型调用句级重写器，不改变核心内容只调整表达方式。
