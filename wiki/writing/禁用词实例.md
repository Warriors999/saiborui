# 禁用词实例

## 概述

D先生文案中的禁用词列表和替代方案。这些词汇要么触发平台审核，要么听着像"广告"而非"说人话"，要么已经被竞品用烂了。

---

## 禁用词分类

### 平台敏感词（触发审核）

| 禁用词 | 风险 | 替代方案 |
|--------|------|---------|
| 最好 | 绝对化用语 | 第一梯队 / 顶流 / 夯 |
| 第一 | 绝对化用语 | 排名靠前 / 这一档里最能打 |
| 全网 | 夸大宣传 | 目前看到的 / 我测过的 |
| 最便宜 | 价格误导 | 这一档性价比拉满 / 同价位没对手 |
| 国家级 | 违禁词 | 不讨论 |

### 电商味词汇（听着像广告）

| 禁用词 | 问题 | 替代方案 |
|--------|------|---------|
| 极致 | PR稿味 | 到位 / 拉满 / 做到头了 |
| 震撼 | 夸张表演 | 确实强 / 有东西的 |
| 全新升级 | 模板套话 | 这一代改了 / 终于加了 |
| 不容错过 | 逼单味 | 值得看一看 / 重点考虑 |
| 颠覆 | 吹太大 | 完全不一样 / 思路换了 |
| 匠心 | 空洞 | 做工细 / 细节到位 |
| 赋能 | 互联网黑话 | 好用 / 能帮到你 |

### 空洞口头禅（竞品用烂了）

| 禁用词 | 问题 | 替代方案 |
|--------|------|---------|
| 我滴妈 | 聒噪 | 不替代——直接删掉 |
| 好家伙 | 聒噪 | 不替代——直接删掉 |
| 你敢信 | 套路 | 这合理吗 / 说实话 |
| 有一说一/不吹不黑 | 廉价客观信号 | 用数据说话 / 我测下来的结果是 |
| 兄弟们（用作填充） | 无意义重复 | 只在实际需要称呼观众时用 |

### 数量限制词

| 词汇 | 限制 |
|------|------|
| 非常 | 全篇不超过2次 |
| 真的 | 全篇不超过3次 |
| 超级 | 全篇不超过1次 |

---

## 竞品对比数据

从B站24+位创作者的口播文本中统计：
- 使用"我滴妈"的创作者: 7/24 (29%)
- 使用"有一说一"作为段落开头的: 11/24 (46%)
- 包含"极致"的: 15/24 (63%)

D先生风格明确不使用这些表达——信息密度和真实态度比音量更重要。
