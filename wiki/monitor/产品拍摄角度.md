# Monitor 产品拍摄角度 Wiki

## 概述

在Monitor（显示器）品类中，产品拍摄角度的选择至关重要。它不仅是展示产品外观设计的窗口，更是传递其核心卖点（如尺寸、曲率、分辨率、刷新率、电竞属性）的关键手段。优秀的拍摄角度能够将显示器的“观看”体验，通过视觉语言转化为观众的“购买”冲动。

本Wiki旨在系统梳理Monitor品类拍摄的核心角度数据、技巧模式及可复用手法，帮助内容创作者高效产出高质量的产品视觉素材。

### ⚠️ 应避免的低级套路

| 套路类型 | 具体表现 | 为什么应该避免 | 替代方案 |
| :--- | :--- | :--- | :--- |
| **情绪宣泄式开头** | “我滴妈！”、“好家伙！”、“这也太牛了吧！” | 短期或许能吸引注意力，但会迅速消耗观众信任，显得不专业、不真诚。观众会觉得你在“演”，而非“真懂”。 | 用**悬念式提问**或**数据锚定**开场，如：“5000块买了5台网吧倒闭的显示器，到底是捡漏还是踩坑？” |
| **空洞口头禅填充** | “有一说一”、“兄弟们”、“懂的都懂” | 暴露内容密度不足，是创作者在思考间隙的填充物。会降低信息传递效率，让观众觉得内容注水。 | 用**具体的操作指令**或**结论性陈述**替代，如：“接下来我们看漏光测试”、“结论是：这台不值得买。” |
| **过度夸张的标题党** | “震惊！”、“全网第一！”、“看完我哭了” | 提高用户预期，但内容无法匹配时，会导致极高的跳出率和负面评论。损害长期IP人设。 | 标题应**明确核心卖点**并**降低预期**，如：“5台网吧二手显示器实测：1台真香，3台是坑。” |
| **廉价的情感煽动** | “为了粉丝，我豁出去了”、“冒着被骂的风险” | 显得刻意且虚假。观众更倾向于相信基于事实和数据的客观分析，而非卖惨或道德绑架。 | 用**客观事实**和**数据**说话，如：“经过测试，这台显示器的色域覆盖只有sRGB的60%。” |
| **无意义的镜头晃动** | 手持拍摄时剧烈晃动、快速无逻辑的运镜 | 造成视觉疲劳，让观众感到不适。尤其在需要展示细节（如坏点、漏光）时，晃动是致命的。 | 使用**稳定器**或**固定机位**。在需要动感时，采用**缓慢平移**或**推拉**。 |

### 📐 可复用的结构模板

1.  **“捡漏/踩坑”决策模板**
    *   **结构：** 价格锚定开场 → 逐台外观/参数介绍 → 核心对比测试（色彩/漏光/拖影） → 价格精算（购入+修复 vs 市价） → 最终购买建议
    *   **适用品类：** 二手数码（手机、电脑、相机）、清仓商品、临期食品、任何存在“信息差”和“价格波动”的品类。
    *   **一句话描述：** 通过“批量测试+精算模型”，为用户提供二手/清仓市场的确定性决策依据，核心是制造“赌博感”和“信息差”。

2.  **“行业解密/避坑”模板**
    *   **结构：** 行业链路图开场（建立权威） → 拆解单一“踩雷”案例（深入技术细节） → 计算“隐性成本”（时间、情绪、健康） → 给出“XX定律/公式” → 预告下期“傻瓜式”检测方法。
    *   **适用品类：** 任何存在“黑幕”或“复杂技术”的行业（如：二手翻新、保健品、护肤品成分、装修材料）。
    *   **一句话描述：** 用专业拆解和信息差，满足用户“看透本质”的需求，建立“行业专家”人设，信息密度和说服力更强。

3.  **“横向对比/横评”模板**
    *   **结构：** 统一场景/参数设定 → 分项对比测试（外观、性能、价格） → 视觉化冲突（并排画面、数据图表） → 分维度总结（优点/缺点） → 按需求推荐。
    *   **适用品类：** 任何存在多个竞品的品类（手机、汽车、家电、软件工具）。
    *   **一句话描述：** 通过“控制变量法”和“视觉化冲突”，将复杂的参数对比转化为直观的视觉体验，帮助用户快速决策。
