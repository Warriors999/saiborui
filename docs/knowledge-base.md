# 知识库与公开范围

[返回首页](../README.md) · [English](knowledge-base.en.md)

仓库内 `wiki/` 保存按品类和主题组织的创作知识，包含拍摄、写作和竞品分析等内容。`rag_system/retrieval/`、`embedding/`、`storage/` 等模块服务于资料检索；向量数据与个人输入通常保留在本地。

截至此次整理，本地 Wiki 还有未提交的改写、新增文件和删除记录。它们涉及对外部视频与素材的分析，尚未逐篇核验来源、引用方式和公开授权，因此没有批量同步。仓库中已经存在的历史内容不因这次整理而自动完成版权审核。

添加内容时应记录来源，确认有权公开引用；避免提交客户 Brief、个人信息、认证材料和未经许可的完整第三方作品。生成内容也需要人工核实。
