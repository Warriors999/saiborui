Data Loops

三个数据闭环

不是一次性生成——系统持续从竞品和绩效中学习，每次运行都比上一次更好

闭环A：竞品 → Wiki → 生成

抖音/B站视频深度分析（转录+视觉+音频三维拆解）→ LLM知识蒸馏编译Wiki页面 → 生成时按卖点相关性提取注入(25000字/次) → 新竞品数据持续更新Wiki → 循环。同品类5次生成自动编译新页面。

25条视频 43 Wiki页 8份报告

闭环B：选题 → 种子 → 挂钩

5平台实时热搜 → AI筛选数码话题 → 多维度评分排序 → topics_seed.txt自动更新 → meme引擎读取种子→生成时匹配相关热点→文案开场挂钩。每日8:57自动运行，7天自动清理过期数据。

5平台 6维评分 HTML看板

闭环C：审计 → 修复 → 回归

12项自动审计(内容质量+结构规范+合规安全) → 失败项分析 → 3轮AutoFix修复(结构修复+LLM修复) → 回归检测(确保不降级) → analytics记录失败模式 → 下次生成前注入针对性改进建议。
